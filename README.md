# OM MORE — Interactive Portfolio

An immersive, interactive personal portfolio inspired by the visual design and interface of **Persona 3 Reload**.

Rather than following a conventional portfolio layout, this project presents personal information, academic achievements, technical skills, and projects through a game-inspired interface with animated transitions and interactive navigation.

## Features

- **Interactive UI:** A game-inspired navigation system with multiple dedicated sections.
- **Animated Transitions:** Custom block-wipe and water-splash transitions between screens.
- **Dynamic Backgrounds:** Section-specific background videos with smooth crossfading.
- **Audio Integration:** Background music and sound effects with independent toggle controls.
- **Keyboard Navigation:** Navigate the interface using keyboard controls.("Enter" to enter a section, "backspace" to return)
- **Controller based navigation:** Navigate also by connecting your controller.
- **Interactive Calendar:** A calendar displaying important academic milestones and events.
- **Detailed Skill Sections:** Explore technical skills and learning progress.
- **Project Showcase:** Dedicated space for projects and practical work.
- **Resume Integration:** Downloadable resume directly from the interface.
- **Responsive Design:** CSS-based layouts designed to adapt to different screen sizes.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Digitechz/om-more-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd om-more-portfolio
   ```

3. Open `index.html` in your browser or run the project using a local development server.

## Navigation

The interface supports keyboard-based navigation:

| Key | Action |
|---|---|
| Arrow Up / Down | Navigate menus |
| Enter / B | Confirm selection |
| Escape / A / Backspace | Go back |
| Mouse | Interact with available elements |
